# Trilha frontend — Reformulação do Superlog

Uma sequência prática para uma estudante iniciante construir uma página clara, bonita, responsiva e acessível, primeiro com HTML, CSS e JavaScript e depois com React.

## Como estudar

Antes de começar, consulte as [instruções de execução](EXECUCAO.md): preparação, pastas, comandos, navegador e resolução de problemas.

Veja também o [registro de verificação](VERIFICACAO.md), que distingue os exemplos testados das etapas ainda não executadas.

1. Leia o objetivo do módulo e faça os exercícios em ordem.
2. Digite o código e observe o resultado no navegador.
3. Confira os critérios de cada exercício antes de avançar.
4. Anote o que mudou, por que mudou e o que ainda não entendeu.
5. Guarde uma versão ao terminar cada módulo. Você pode copiar a pasta até aprender Git.

Não há prazo obrigatório. Divida cada exercício em sessões curtas e repita quando precisar. Não precisa instalar ferramentas avançadas para começar: um editor de código e um navegador são suficientes nos primeiros módulos.

## Projeto final

Uma página inicial do Superlog com apresentação, explicação do método, públicos, etapas de funcionamento, depoimentos reais quando disponíveis, perguntas frequentes e contato. Uma pessoa deve conseguir entender a proposta, encontrar a informação que precisa e identificar o próximo passo.

Referência de conteúdo: [site Superlog](https://metodosuperlog.com.br/), consultado em 19/10/2026. A trilha propõe uma reformulação didática; não constitui uma auditoria visual do site atual. Use textos de trabalho e imagens temporárias identificadas durante os exercícios. Não invente depoimentos, resultados, números ou promessas de saúde. Antes de apresentar o projeto como oficial, confirme conteúdo e autorização de uso dos materiais.

## Organização sugerida

Crie uma pasta `projeto-superlog` ao começar o módulo 2. Nos primeiros módulos, ela conterá `index.html`, `css/style.css`, `js/script.js` e `assets/`. No módulo 8, você criará outro projeto para a versão React e manterá a versão anterior para comparação.

## Registro de aprendizagem

Ao concluir um exercício, responda:

- O que construí?
- Qual decisão tomei e por quê?
- Como conferi o resultado?
- O que quero melhorar na próxima revisão?

O projeto estará concluído quando atender aos critérios do módulo 9, e não apenas quando todos os arquivos existirem.
