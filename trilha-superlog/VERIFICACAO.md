# Verificação dos materiais — 02/11/2026

O repositório contém enunciados e exemplos em Markdown. Ainda não contém as implementações dos 45 exercícios nem um aplicativo React instalado. Assim, não é correto afirmar que todos os exercícios foram executados.

## Verificado

- Links relativos entre os documentos: nenhum destino ausente.
- Sintaxe dos dois blocos JavaScript de `apoio/exemplos.md`: aceita pelo Node.js 22.14.0.
- Função de busca executada com quatro casos: maiúsculas com espaços, termo vazio, somente espaços e termo inexistente. Todos passaram.
- Menu executado com objetos simulando os elementos e eventos do navegador: estado inicial móvel, abertura, fechamento com Escape, retorno de foco, passagem para desktop e retorno ao celular. Todos passaram.

## Ainda não verificado

- Compilação e execução dos três exemplos JSX. React, Vite e compiladores JSX não estão instalados neste projeto.
- Instalação e execução integral dos comandos de criação do projeto React.
- Implementações de formulário, preferência local e demais exercícios que atualmente existem apenas como enunciados.
- Responsividade, contraste, imagens e testes de usabilidade de uma página final, que ainda será construída.

Não foram encontradas falhas nos casos executados. Isso não comprova que todos os exercícios ou exemplos funcionem de ponta a ponta. Conforme as implementações forem adicionadas, esta lista deve ser atualizada com os testes reais e eventuais correções.
