# Glossário inicial

| Termo | Significado neste projeto |
| --- | --- |
| HTML | Define a estrutura e o significado do conteúdo. |
| Semântica | Escolher elementos pela função: título, navegação, botão, seção. |
| CSS | Controla a aparência e a distribuição visual. |
| Seletor | Identifica os elementos que receberão um estilo ou uma ação. |
| Responsividade | Adaptação do layout ao espaço disponível. |
| Breakpoint | Largura em que uma regra de layout muda. |
| DOM | Representação da página que o navegador disponibiliza ao JavaScript. |
| Evento | Algo que acontece, como clique, digitação ou envio de formulário. |
| Array | Lista de valores. |
| Objeto | Conjunto de propriedades e valores. |
| API | Interface pela qual programas trocam dados ou solicitam operações. |
| JSON | Formato textual usado para representar e transportar dados. |
| fetch | Função do navegador usada para solicitar recursos. |
| npm | Ferramenta para gerenciar pacotes e executar scripts de um projeto. |
| Componente | Parte reutilizável da interface, com uma responsabilidade. |
| JSX | Sintaxe usada para descrever a interface em componentes React. |
| Propriedades (props) | Dados recebidos por um componente. |
| Estado (state) | Informação que muda e influencia o que aparece na interface. |
| Efeito | Sincronização com algo externo ao React, como uma requisição. |
| Build | Geração de arquivos preparados para distribuição. |
| Usabilidade | Facilidade para compreender e realizar tarefas na interface. |
| Acessibilidade | Condições para pessoas com diferentes formas de percepção e interação usarem a página. |
